# 사전 확정한 분석 계획서 (v3 확정본, 2026-09-09) — 1–3절 원문

실행 전에 고정한 부분(1절 가설·기각 조건, 2절 벤치마크 구성, 3절 지표·검정)을 원문 그대로 싣는다. 원 문서의 0절과 4–9절(일정·계산량·집필 계획 등)은 분석 계획이 아니므로 싣지 않았다. 본문의 "1편"은 Ahn et al. (2026a, Digital Discovery)를 가리킨다.

---

## 1. 주장과 가설

**문제 설정**: 제약식은 아무도 모른다. 과거 실험 기록(웜스타트)은 대부분 feasible한 점뿐이다(실패한 실험은 기록에 잘 남지 않는다). infeasible 제안은 실험 실패로 예산만 소모한다.

**주장**: 기록 데이터로 학습한 조건부 확산 생성기는 feasible 영역을 암묵적으로 학습하므로, 제약을 모르는 상태에서도 **첫 실험부터** 제안이 feasible 영역에 머물고, 국소 정련(LE)을 붙여도 이 성질이 유지되어 성능 손실이 작다.

**문헌상 위치**: unknown/crash-constraint BO(Gelbart 2014; Bachoc 2020), Safe BO(SafeOpt, Sui 2015; Berkenkamp), 제약 학습 BO(SCBO, Eriksson & Poloczek 2021), 확산 기반 최적화(Diffusion-BBO, Chen 2026). 기존 방법은 위반을 겪으며 제약을 배우거나 강한 가정 아래 보수적으로 움직인다. DALI는 기록 데이터에서 안전 영역을 바로 읽는다.

**사전 고정 가설**

| 가설 | 내용 | 기각 조건 |
|---|---|---|
| H1 준수 | 제약 비인지 베이스라인(TuRBO·GA·BO·RS) 대비 DALI+LE의 누적 위반 수 V가 유의하게 낮다 | Tier 1 16구성 중 4개 베이스라인 모두에 유의 승리한 구성 < 12 |
| H1b 초기 안전 | 첫 위반까지의 평가 수 T₁이 SCBO를 포함한 모든 베이스라인보다 길다 | 합산 생존곡선 log-rank 비유의(vs SCBO) |
| H2 안전의 비용 | DALI+LE의 feasible regret은 최강 베이스라인 대비 격차가 작고, 회피한 위반 1회당 regret이 SCBO보다 낮다 | DALI+LE의 최종 feasible best가 웜스타트 최고값 대비 유의 개선 없음 |
| H3 메커니즘 | 준수는 in-distribution 생성에서 온다. 확산 제거(LE-only, verifier+random) 시 준수가 사라지고 clipping·verifier는 준수를 설명하지 못한다 | LE-only V ≈ DALI+LE V (대표 4구성 중 3개 이상 비유의) |
| H4 한계 | 경계 최적점·웜스타트 오염·단절 집합에서 준수 또는 성능이 저하된다 — 정도를 정량화 | (기각 아님) |
| H5 실데이터 | 데이터 유도 은닉 feasibility 아래 세 공정 데이터셋에서 H1·H2 순서가 유지된다 | 3 중 2 이상에서 H1 불성립 |

H4는 "실패하는 조건"을 우리가 먼저 보여주는 절이다. 1편의 정직한 프레이밍 태도를 유지한다.

## 2. 벤치마크 구성

### 2.1 합성 제약 스위트 (주 실험)
기본 지형: 1편 track B의 6D 가우시안 혼합(c₀ 고정, 데코이 7개, s₀ = 0.08) 재사용. 제약 g(x) ≥ 0 부과. 은닉 제약·death penalty(f_pen = max(f_warm) + 0.1·range)·feasible-only 웜스타트(기각 샘플링 200점)는 1편 track C와 동일.

요인 1 — 제약 기하 (4종)

| 기호 | 기하 | 정의 | 의도 |
|---|---|---|---|
| G1 | convex | 구 ‖x − a‖ ≤ ρ | 가장 쉬운 경우 |
| G2 | non-convex | (1/6)Σ sin(2πxᵢ) ≥ τ (1편 cgm6) | 1편 연속 |
| G3 | disconnected | 두 구의 합집합, c₀는 한쪽에만 | 웜스타트가 한쪽만 덮을 때 |
| G4 | thin band | \|h(x)\| ≤ ε (h: 2차) | 좁은 운전창, 경계 양쪽이 위험 |

요인 2 — feasible 비율 (3수준): 0.5 / 0.2 / 0.05. ρ·τ·ε 조정 후 MC(20만 점)로 ±0.02 이내 확인.
요인 3 — 최적점 위치 (2수준): interior(c₀ 마진 ≥ 0.1·범위) / boundary(마진 ≈ 0.01). c₀ 고정, 제약을 평행이동.

- **Tier 1 (필수, 16구성)**: 4 기하 × 3 비율 × interior (12) + 4 기하 × 비율 0.2 × boundary (4).
- **Tier 2 (선택, 8구성)**: boundary × 비율 0.5/0.05.

### 2.2 한계 조건 (H4)
비율 0.2·interior 고정, 4 기하:
- 웜스타트 오염 0 / 10 / 30 % (infeasible 점으로 교체). 기본은 라벨 없음(전부 학습). 라벨 있음 조건은 2순위(feasible만 학습 vs 플래그 조건화).
- 웜스타트 크기 200 / 50 (G2·G3만).

### 2.3 차원 확인
2D(1편 cbranin2 그대로), 10D(Levy 10D + G1·G2). spot check.

### 2.4 실공정 데이터셋 (H5)
SFS·NOMC·CCPP. 은닉 feasibility 오라클: 전체 데이터셋을 표준화한 뒤 kNN₅ 거리가 held-out 데이터의 99번째 백분위를 넘으면 infeasible("기록된 운전 영역 밖은 실패"를 코드화). 임계 95/99/99.9 % 민감도는 SI. 웜스타트는 데이터에서 뽑으므로 자동 feasible. 1편 베이스라인은 penalty 없이 돌린 것이므로 **전부 재실행**.

### 2.5 비교 방법 (8개)

| 방법 | 제약 정보 | 역할 |
|---|---|---|
| DALI (1편 구성) | 없음 | 제안 방법 |
| DALI+LE (b_local = 2) | 없음 | 제안 방법(정련 포함) |
| LE-only | 없음 | 확산 제거 컨트롤 |
| TuRBO / GA / BO(gp_hedge) / RS | 없음(penalty 값만) | 제약 비인지 베이스라인 |
| SCBO | 평가 후 제약 마진 m(x) 관측 → 제약 GP 학습 | 제약 학습 베이스라인. DALI는 m(x)를 보지 못하므로 SCBO에 유리한 비교 |
| cTuRBO-known | 제약식 완전 인지 | 상한선 참조점 |

구현: SCBO는 BoTorch 공식 구현 래핑. LE 계열은 `run_dali_le.py` 그대로. 모든 방법에 후보 좌표·feasible 플래그·마진 로깅을 기본 탑재(Fig 5용).

## 3. 지표와 통계 (사전 고정)

### 3.1 지표
| 지표 | 정의 | 가설 |
|---|---|---|
| V | 100회 평가 중 누적 infeasible 제안 수 (주 지표) | H1 |
| T₁ | 첫 위반까지의 평가 수 (100회 무위반 = 우측 절단) | H1b |
| f_best^feas, r | feasible 제안 중 최고 목적값, feasible simple regret = f_best^feas − f* | H2 |
| 안전 비용 | (r_method − r_bestbaseline)/(V_bestbaseline − V_method) | H2 |
| 마진 분포 | 제안점의 m(x) | H3·H4 |
| d_kNN | 제안점의 웜스타트 kNN₅ 거리(표준화) | H3 |
| 후보 단계 feasible 비율 | 생성 직후(필터·clip 전) 200후보 중 feasible 비율 | H3 |

### 3.2 검정
- 시드: 1편 10개(43,77,777,34,1004,0,1,2,3,7) + 신규 10개(11,13,17,19,23,29,31,37,41,47). Tier 1은 20, 나머지 10.
- 구성별: DALI+LE vs 각 베이스라인 양측 Mann–Whitney U, 구성 내 Holm 보정, Cliff's δ 병기, 평균은 부트스트랩 95 % CI.
- T₁: Kaplan–Meier + log-rank(구성별·합산).
- 격자 수준(H1): 16구성 중 유의 승리 수 + sign test. 회귀 요약(V ~ 방법 + 기하 + 비율)은 보조.
- H3: DALI+LE vs LE-only vs verifier+random, 같은 절차.
- 전 결과(p·δ·CI)를 SI Table S1로 전량 공개.
